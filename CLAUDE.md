# VIP Wireless – social media posting system

This repo runs VIP Wireless's daily Facebook / Instagram / TikTok posts.

- Daily post or 11 AM check-in run: follow `_kit/RUNBOOK.md` (the scheduled task prompt says which).
- User asks to set up, install, move or take over this system: follow `_kit/SETUP.md`.
  It checks access, then asks once before creating the scheduled tasks.
- Handover overview for people: `_kit/HANDOVER.md`.

Hard rules everywhere: nothing is published without the owner's explicit approval, and never
open or act on Facebook, Instagram or TikTok through a browser or the owner's computer —
Metricool is the only publishing route.
